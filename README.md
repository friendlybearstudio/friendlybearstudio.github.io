# friendlybearstudio.com

Friendly Bear Studio's website, served by GitHub Pages at https://friendlybearstudio.com (custom domain in `CNAME`; DNS at Cloudflare).

- `/` studio page
- `/tabbys-box/` Tabby's Box support page (App Store "Support URL")
- `/tabbys-box/privacy/` Tabby's Box privacy policy (App Store "Privacy Policy URL", linked in the app's Settings → Credits)

Plain HTML and one stylesheet, no scripts, no cookies, no outside fonts. Source of truth is this repo; a copy lives in the private Tabbysbox repo under `website/`. Change the privacy page's "Effective" date whenever its content changes.
